# Tabs

Carril hundido (`surface-sunken`) con la pestaña activa en `lilac` y trazo interior de tinta. Para dos o tres vistas de la misma lista ("Suggested plans" / "Done plans"); para navegar entre páginas está Nav.

- Cada pestaña lleva su contador en `bw-count` (mono, cápsula de borde).
- Nunca amarillo: la selección es siempre lila.
