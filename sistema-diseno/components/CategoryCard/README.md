# CategoryCard

Tarjeta pequeña de categoría en `snow`: dibujo en línea, contador de planes hechos (Unbounded) y nombre (mono en mayúsculas). Van todas en una fila; la activa pasa a `lilac` con `shadow-pop`.

- Solo cuenta, no "completa": ningún total ni porcentaje.
- El dibujo hereda el color del texto (`currentColor`).
