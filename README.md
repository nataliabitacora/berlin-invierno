# Berlín en invierno

Pequeña web para descubrir Berlín cuando hace frío: mercados navideños, museos,
paseos nevados, sitios para entrar en calor y comida típica.

## Cómo abrirla

No necesita instalar nada. Abre `index.html` en el navegador:

```bash
open index.html
```

## Archivos

- `index.html` – estructura de la página
- `style.css` – estilos
- `lugares.js` – los datos de cada lugar (edítalo para añadir más)
- `app.js` – filtros, botón "Sorpréndeme" y lista de visitados (se guarda en el navegador)
